### Skills to Know About
- **/security-review** — Audits the pending changes on the current branch for security issues. The team's most-used command — runs before merging anything that touches auth, payments, or user input.
- **/review** — Reviews a pull request end-to-end. Use on PRs you're about to merge or want a second pair of eyes on.
- **/simplify** — Reviews recently changed code for reuse opportunities, quality, and efficiency, then fixes what it finds. Good cleanup pass after a feature is working but before the PR.
- **/insights** — Generates a usage analytics report of your Claude Code sessions. Useful periodically to see your patterns.
